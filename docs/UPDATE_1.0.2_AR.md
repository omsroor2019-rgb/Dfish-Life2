# تحديث DFISH LIVE 1.0.2

## ما تم تعديله

- إضافة دوري أبطال أوروبا ودوري أبطال آسيا للنخبة ودوري أبطال آسيا 2 إلى قائمة البطولات المسموح بها.
- الإبقاء على الدوري اليمني، ودوريات الخليج، والدوريات الأوروبية من الدرجة الأولى الموجودة في القائمة.
- جلب الصفحات المتعددة من نتائج API-Football قبل تصفية المباريات، مع ترتيبها حسب موعد البداية بتوقيت `Asia/Aden`.
- فصل فلاتر المباريات: الكل، مباشر، قادمة، انتهت، مؤجلة، ملغاة.
- إضافة معلومات الملعب والمدينة والحكم ونتيجة الشوط الأول إلى ملخص المباراة.
- إضافة تبويبات أحداث المباراة والتشكيلة وإحصائيات الفرق وإحصائيات اللاعبين والمواجهات السابقة.
- تعريب أسماء البطولات والدول والبطولات القارية وحالات المباراة.
- تقليل النصوص التوضيحية في الشاشة الرئيسية وقسم البث.
- تحسين WebView لروابط HTTPS المختصرة وصفحات التحويل، وتفعيل JavaScript وتشغيل الوسائط والكوكيز الخارجية وفتح الروابط المنبثقة داخل نفس الشاشة.
- إيقاف طلب الفحص المؤقت قبل تحميل ملفات الفيديو المباشرة حتى لا يحاول التطبيق تنزيل البث كاملاً.
- تعديل GitHub Actions حتى لا يفشل تنسيق/اختبار Dart إذا لم يوجد مجلد `test` في المستودع.

## حدود التغطية

توفر المباريات والتشكيلات وإحصائيات اللاعبين والحكم والملعب يعتمد على تغطية API-Football للبطولة والموسم والمباراة، وعلى خطة المفتاح المستخدم. قد تظهر أسماء الأندية واللاعبين باللغة التي يعيدها مزوّد البيانات عندما لا يوفر اسماً عربياً.

## تشغيل البناء

1. ضع `API_FOOTBALL_KEY` في GitHub Repository Secrets بالاسم نفسه تماماً.
2. ارفع محتويات المشروع المحدثة إلى الفرع `main`.
3. افتح تبويب Actions وشغّل `Build DFISH LIVE APK`.
4. عند نجاح البناء، نزّل `DFISH-LIVE-Android-APK` من Artifacts.

لا تضع مفتاح API داخل ملفات Dart ولا تشاركه في الصور أو المحادثات.
