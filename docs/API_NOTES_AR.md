# ملاحظات تكامل API-Football

- المضيف: `https://v3.football.api-sports.io/`
- طريقة المصادقة: ترويسة `x-apisports-key`.
- المنطقة الزمنية: `Asia/Aden` (اليمن UTC+3).
- مباريات يوم محدد: `/fixtures?date=YYYY-MM-DD&timezone=Asia/Aden`.
- المباريات المباشرة: `/fixtures?live=all&timezone=Asia/Aden`.
- أحداث المباراة: `/fixtures/events?fixture={fixture_id}`.
- التشكيلات: `/fixtures/lineups?fixture={fixture_id}`.
- إحصائيات المباراة: `/fixtures/statistics?fixture={fixture_id}`.
- ترتيب الدوري: `/standings?league={league_id}&season={year}`.
- الهدافون: `/players/topscorers?league={league_id}&season={year}`.
- صناع الأهداف: `/players/topassists?league={league_id}&season={year}`.
- معلومات اللاعب: `/players?id={player_id}&season={year}`.
- معلومات النادي ولاعبيه: `/teams?id={team_id}` و`/players?team={team_id}&season={year}`.
- انتقالات اللاعب: `/transfers?player={player_id}`.
- الدوريات للموسم المختار: `/leagues?season=YYYY` ثم تصفية الدرجة الأولى الخليجية واليمنية والأوروبية.
- مواسم الخطة المجانية في 2026: 2022 و2023 و2024؛ راجع لوحة حسابك لأن النطاق يتغير مع السنوات والخطة.
- فحص صلاحية الاتصال: `/status`.

## مكان المفتاح

يُمرر المفتاح من GitHub Secret باسم `API_FOOTBALL_KEY` إلى البناء باستخدام `--dart-define`. يظهر المفتاح داخل APK الناتج ويمكن استخراجه منه؛ لا ترفعه في ملفات المصدر. استخدم مفتاحاً مخصصاً للتطبيق وراقب الحصة وألغ أي مفتاح سبق نشره أو مشاركته.

## حدود البيانات والاشتراك

- الحصة اليومية ومعدل الطلبات والتغطية تعتمد على خطة API-Football النشطة؛ راجع لوحة الحساب قبل الإطلاق.
- يطبق التطبيق تخزيناً مؤقتاً داخل الذاكرة لتقليل تكرار طلبات المباريات والدوريات.
- لا تتوفر التشكيلات والإحصائيات لكل مباراة أو بطولة بالضرورة.
- شعارات الفرق والدوريات وصور اللاعبين تُعرض عند توافر روابطها في استجابة API.
- API-Football مصدر بيانات وإحصائيات، وليس مزود فيديو بث للمباريات.
- قد تتأخر بعض البيانات أو لا تتوفر بسبب التغطية أو توقيت التحديث أو اشتراك الحساب.

راجع التوثيق الرسمي: https://www.api-football.com/documentation-v3


## تنبيه الخطة المجانية في 2026

وفق صفحة API-Football الرسمية بتاريخ 26 أكتوبر 2026، مواسم الخطة المجانية المتاحة هي من السنة الحالية ناقص 4 إلى ناقص 2، أي 2022 و2023 و2024 في 2026. لذلك لا يمكن جلب مباريات اليوم أو نتائج الموسم الجاري من الحساب المجاني؛ شاشة المباريات تعرض رسالة واضحة بدلاً من طلب موسم غير متاح. يلزم اشتراك يدعم الموسم الحالي للحصول على النتائج المباشرة والبيانات الجارية. كما أن الخطة المجانية محدودة بـ 100 طلب يومياً، و10 طلبات في الدقيقة. راجع لوحة الحساب لاحتمال تغير الحدود.

تتم مشاركة الطلبات المتزامنة لنفس عنوان API، ويُحفظ الرد في الذاكرة وعلى الجهاز. عند اكتشاف حد الطلبات اليومي، يتوقف التطبيق عن تكرار الطلبات حتى منتصف الليل UTC ويستخدم البيانات المحفوظة إن كانت ضمن العمر المحدد.

يعمل التحديث التلقائي كل خمس دقائق فقط عندما يكون تبويب الرئيسية أو المباريات هو التبويب المحدد والتطبيق في الواجهة. هذا إعداد محافظ لتقليل استهلاك الحصة؛ لا يوفر مزود API تحديثاً فورياً عند استخدام خطة أو حصة محدودة.
