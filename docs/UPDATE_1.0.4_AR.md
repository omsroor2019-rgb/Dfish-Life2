# تحديث DFISH LIVE 1.0.4

## إصلاحات هذا الإصدار

- إزالة معامل `page` من طلب `fixtures`؛ هذا المسار لا يقبل معامل `page`، وكان سبب رسالة `The Page field do not exist`.
- استخدام التاريخ مع المنطقة الزمنية `Asia/Aden` لجلب مباريات اليوم.
- توحيد عرض أوقات المباريات بصيغة عربية 12 ساعة (`9:30 م` / `9:30 ص`) في شاشة المباريات والبث.
- تطبيع أسماء الدول التي تصل بشرطة مثل `Saudi-Arabia` و`United-Arab-Emirates` حتى لا تختفي مسابقاتها بسبب اختلاف التنسيق.
- توسيع قائمة مسابقات آسيا المختارة، مع الدوريات الأوروبية الكبرى ودوريات الخليج واليمن، وإضافة بطولات UEFA Europa / Conference وAFC Challenge League.
- توضيح أن روابط شعارات المباراة اختيارية ومنفصلة عن روابط تشغيل البث.
- تحسين محاولة حل تحويلات روابط البث باستخدام HEAD أولاً ثم GET بنطاق بايت واحد عند الحاجة، مع ترك التشغيل داخل WebView.

## حدود التغطية

توافر النتائج والتشكيلات والإحصائيات يتبع تغطية البطولة والموسم والمباراة في API-Football وخطة المفتاح. وجود اسم البطولة في قائمة التغطية لا يعني أن كل بيانات كل مباراة متاحة. بعض مواقع البث تمنع التشغيل المضمّن؛ لا يمكن ضمان تجاوز قيود الموقع، لكن التطبيق لا يفتح Chrome تلقائياً لهذا المسار.

## الاختبار

أضيفت اختبارات لوظيفة الوقت وتطبيع اسم البلد وقائمة الدوريات. يجب تشغيل `flutter test` و`flutter build apk --release` في GitHub Actions قبل اعتبار ملف APK صالحاً للنشر.
