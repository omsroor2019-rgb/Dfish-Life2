# تحديث DFISH LIVE 1.0.7

## المباريات
- لم تعد قائمة الرئيسية تقتصر على ست مباريات. تعرض حتى 12 مباراة وتوفر انتقالاً إلى صفحة المباريات الكاملة.
- يجري ترتيب المباريات المباشرة أولاً، ثم القادمة، ثم المنتهية والمؤجلة.
- داخل كل مجموعة حالة، تعطى الأولوية للبطولات القارية الكبرى والدوريات الأوروبية الكبرى والدوريات الخليجية واليمنية ثم بقية البطولات المدعومة.
- توسعت قائمة البطولات المعتمدة لتشمل دوريات كبرى من أمريكا الجنوبية والشمالية وأفريقيا، وبطولات قارية رئيسية.

## البطولات والمواسم
- لم يعد التطبيق يحصر قائمة المواسم في 2026 و2027.
- يجلب سنوات المواسم من API-Football ثم يختبر أحدث السنوات، ويحتفظ فقط بالمواسم التي يعيد فيها المزود دوريات مدعومة.
- عند رفض موسم صراحةً بسبب صلاحية الخطة، ينتقل التطبيق إلى موسم أقدم. أخطاء الحساب الموقوف أو المفتاح أو الشبكة لا يتم إخفاؤها بمحاولات مواسم أخرى.
- تم تصحيح تسمية المناطق للبطولات الأوروبية والآسيوية والأفريقية وأمريكا الشمالية والجنوبية والعالمية.

## ملاحظات مهمة
- عدد المباريات النهائي يعتمد على وجود مباريات في ذلك اليوم وعلى البطولات التي يغطيها حساب API-Football. ترتيب القائمة لا يستطيع إنشاء مباريات غير موجودة في مصدر البيانات.
- التطبيق لا يتجاوز إيقاف الحساب أو انتهاء المفتاح أو حدود الخطة. يجب أن تكون حالة حساب API فعالة.
- لا يتغير إعداد Firebase أو قواعد Firestore أو GitHub Secret في هذا التحديث.
