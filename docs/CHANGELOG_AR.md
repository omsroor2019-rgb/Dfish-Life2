# سجل تعديلات DFISH LIVE

## نسخة تصحيح البطولات والبث

- استبدال جلب البطولات الحالية بطلب مرتبط بالموسم المختار حتى لا يختار التطبيق موسم 2026 غير المتاح للحساب المجاني.
- اعتماد قائمة منتقاة للدرجة الأولى في دول الخليج واليمن وأبرز الدوريات الأوروبية فقط.
- ترجمة أسماء البطولات والدول المعروفة والمصطلحات الرياضية الأساسية إلى العربية.
- إضافة اختيار الموسم وعرض جميع مجموعات الترتيب بدلاً من المجموعة الأولى فقط.
- التحقق من تغطية كل من الترتيب والهدافين وصناعة الأهداف قبل الطلب.
- اعتماد مسارات API-Football المخصصة للترتيب والهدافين وصناعة الأهداف.
- نقل مفتاح API إلى GitHub Secret باسم `API_FOOTBALL_KEY` وتمريره عند بناء APK.
- إزالة تقييد النطاق الواحد من WebView حتى تعمل التحويلات الآمنة HTTPS من الروابط المختصرة إلى صفحات Blogger ومشغلات التضمين.
- إضافة اختبارات وحدات لتصفية قائمة الدوريات وترجمتها وتغطيتها.

## حدود يجب معرفتها

- في 2026، توضح وثائق API-Football أن الخطة المجانية تغطي المواسم 2022 و2023 و2024 فقط؛ يلزم اشتراك يشمل الموسم الجاري للحصول على مباريات 2026 والنتائج المباشرة.
- الخطة المجانية محدودة بـ 100 طلب يومياً و10 طلبات في الدقيقة. عند توزيع APK على عدة مستخدمين سيشتركون في حصة المفتاح نفسها.
- مفتاح API الذي يمرر وقت البناء يمكن استخراجه من APK؛ لا يعتبر سرياً بعد التوزيع.
- لم يتم تنفيذ بناء Flutter أو اتصال API حقيقي داخل بيئة إعداد هذه الحزمة؛ يجب أن ينجح GitHub Actions وتُختبر الاستجابات على مفتاح الحساب قبل النشر.

## الإصدار 1.0.5 — تخزين ذكي وتقليل استهلاك API

- إضافة تخزين مؤقت دائم لاستجابات API بصيغة JSON باستخدام SharedPreferencesAsync، مع مدد مختلفة للمباريات والبطولات والإحصائيات.
- الاحتفاظ بآخر بيانات صالحة وعرضها عند انقطاع الإنترنت أو انتهاء الحصة اليومية، ضمن حدود عمر بيانات مختلفة حسب نوعها.
- منع الطلبات المتزامنة المكررة لنفس الرابط عبر مشاركة Future واحدة.
- حفظ حالة استنفاد الحصة اليومية حتى منتصف الليل UTC، مع إيقاف إعادة المحاولة المتكررة.
- تحديث المباريات تلقائياً كل خمس دقائق عند بقاء تبويب الرئيسية أو المباريات ظاهراً، وإيقاف طلب التحديث عندما يكون التطبيق في الخلفية.
- تخزين شعارات الفرق والبطولات ومصادر البث على القرص باستخدام cached_network_image.
- تحويل أوقات انطلاق المباريات إلى صيغة عربية 12 ساعة.

ملاحظة: التخزين المؤقت يقلل الطلبات ويحافظ على آخر بيانات معروفة، لكنه لا يستطيع إنشاء نتائج جديدة أو تحديثها أثناء توقف API أو انتهاء الحصة.


## 1.0.6 — دعم مواسم 2026 و2027

- جلب سنوات المواسم المتاحة من `/leagues/seasons` مع تخزينها 24 ساعة.
- عرض الموسم الجاري والموسم التالي في شاشة البطولات.
- اعتماد سنة بداية الموسم: 2026 تعني 2026/2027 و2027 تعني 2027/2028.
- استخدام سنة الموسم الجاري لملفات اللاعبين وقوائم لاعبي الأندية بدلاً من اختيار آخر عنصر من قائمة سنوات قديمة.
- توضيح أن توفر الموسم يعتمد على الخطة وتغطية البطولة، وليس على ظهوره في قائمة السنوات وحدها.


## الإصدار 1.0.7 — تكامل Highlightly والتعريب

- إضافة Highlightly Football API كمصدر اختياري مع إبقاء API-Football كما هو.
- إضافة تبويب مصدر Highlightly للترتيب، وقراءة المواسم من `seasons` التي يعيدها كل دوري بدلاً من فرض سنوات ثابتة.
- إضافة جلب أحداث المباراة والتشكيلات ورسم الملعب وإحصائيات الفريقين وصندوق إحصائيات كل لاعب.
- إضافة ملف اللاعب وإحصائياته حسب البطولة، وسجل الانتقالات والإصابات والقيمة السوقية والشائعات عندما يعيدها المزود.
- إضافة تفاصيل الملعب والحكم والطقس وتوقعات المباراة والأخبار المرتبطة عندما تكون متوفرة.
- مطابقة مباراة API-Football بمباراة Highlightly حسب التاريخ والفريقين قبل استخدام معرّف المصدر الجديد. عند غياب التطابق أو المفتاح، يستمر التطبيق باستخدام المصدر الحالي.
- إضافة Cache دائم ومنع الطلبات المتزامنة المكررة، وتحديث تبويبات الأحداث الحية كل دقيقة أثناء فتح المباراة.
- توسيع قاموس تعريب المصطلحات الرياضية والبطولات والدول والأندية واللاعبين الشائعين.
- إضافة GitHub Secret اختياري باسم `HIGHLIGHTLY_API_KEY` دون تغيير `API_FOOTBALL_KEY` أو إعدادات Firebase.

ملاحظة: لم يتم اختبار استجابات حساب Highlightly الحقيقي أو تشغيل Flutter SDK أثناء إعداد هذه الحزمة. الأسماء غير الموجودة في قاموس التعريب تبقى كما يرسلها المزود لتجنب تهجئة عربية غير دقيقة. كما أن مفتاح API المضمن في APK قابل للاستخراج، وحد Basic اليومي مشترك بين جميع نسخ التطبيق التي تستخدم المفتاح نفسه.
