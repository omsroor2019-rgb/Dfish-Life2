# نظام التخزين الذكي — DFISH LIVE 1.0.5

## ما الذي يفعله؟

1. **تخزين دائم لردود API:** تُحفظ استجابات JSON في الجهاز، وتبقى بعد إغلاق التطبيق وإعادة تشغيله.
2. **تخزين داخل الذاكرة:** الطلبات المتكررة خلال مدة الصلاحية لا تعود إلى الشبكة.
3. **منع الطلبات المتزامنة:** إذا طلبت الرئيسية والمباريات عنوان API نفسه في اللحظة نفسها، يشتركان في طلب واحد.
4. **البيانات القديمة عند التعطل:** إذا انتهت مدة الصلاحية وفشل الاتصال، يعرض التطبيق آخر رد محفوظ ضمن فترة السماح المحددة، ويعرض ملاحظة «آخر بيانات محفوظة».
5. **حماية الحصة اليومية:** عند اكتشاف رسالة تجاوز الحد اليومي، يتوقف التطبيق عن تكرار طلبات API حتى وقت التجدد المتوقع، ويعتمد على التخزين المحلي.
6. **تحديث مباشر محافظ:** يجدد تبويب الرئيسية أو المباريات البيانات كل خمس دقائق فقط عندما يكون التبويب محدداً والتطبيق في الواجهة.
7. **تخزين الصور:** تستخدم شعارات الفرق والبطولات والبث `cached_network_image` لتخزين الصور على الجهاز بعد أول تنزيل.

## مدد التخزين

| البيانات | الصلاحية قبل إعادة الطلب |
|---|---:|
| مباريات اليوم والمباريات المباشرة | 4 دقائق و30 ثانية |
| نتائج الأيام السابقة | 24 ساعة |
| جدول الأيام القادمة | 3 ساعات |
| البطولات والمواسم | 24 ساعة |
| أحداث المباراة وإحصاءاتها | دقيقتان |
| التشكيلات | 10 دقائق |
| ترتيب الدوري والهدافون وصناع الأهداف | ساعتان |
| المواجهات السابقة | 7 أيام |
| شعارات الفرق والبطولات | تخزين صورة على القرص |

## حدود مهمة

- في أول تشغيل لهذا الإصدار، لا توجد بيانات قديمة في مخزن الإصدار الجديد؛ يجب أن ينجح طلب واحد على الأقل كي يبدأ حفظ البيانات.
- التخزين المؤقت لا ينشئ مباريات جديدة ولا يحدّث النتيجة عندما تكون خدمة API أو حصة الحساب متوقفة. سيعرض آخر بيانات تم جلبها بنجاح فقط.
- كل مستخدمي نسخة التطبيق يستخدمون مفتاح API المضمّن نفسه؛ لذلك يتشاركون الحصة اليومية. التخزين يقلل الاستهلاك لكنه لا يرفع حدود اشتراك مزود البيانات.
- قد لا تكون كل تفاصيل المباريات متاحة لكل مسابقة أو موسم حتى مع وجود بيانات المباراة الأساسية.
- لا تُخزّن كلمات المرور أو رموز Firebase السرية داخل هذا المخزن.

## الملفات التي تغيرت في هذا الإصدار

- `pubspec.yaml` — إضافة `cached_network_image` ورفع رقم الإصدار.
- `lib/services/football_api.dart` — التخزين الدائم، صلاحية البيانات، منع التكرار، النسخة الاحتياطية وإيقاف الطلبات عند تجاوز الحد.
- `lib/main.dart` — التحديث كل خمس دقائق عند نشاط تبويب كرة القدم، عرض تنبيه النسخة القديمة، وتخزين شعارات الفرق والبطولات.
- `lib/streams/streams_screen.dart` — التخزين المحلي لشعارات مصادر البث.
